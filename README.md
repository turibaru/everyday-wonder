One sentence, up to 200 characters, that makes a small everyday moment strange and new — an entry for the [Everyday Wonder](https://make.fun/c/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3) bounty on [make.fun](https://make.fun).

`main.ts` reads `entry.txt` at runtime and writes it verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
